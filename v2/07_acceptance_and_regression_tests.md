# Acceptance and Regression Tests

**Workflow:** `GSLS-3A-2.0`

Production agents must not read the gold during these tests. Compare only after production artifacts are frozen.

## 1. Core scoring dimensions

Score each 0–4:

1. primary-reading fidelity;
2. secondary activation specificity;
3. typed relational bridge quality;
4. primary-effect clarity;
5. temporal reactivation;
6. multi-channel recall;
7. evidence boundaries;
8. resistance to theme-only overreach;
9. natural synthesis quality;
10. audit closure.

## 2. Required diagnostic passages

### Gold-reference passage

Use the passage corresponding to the quarantined gold document.

Pass criteria:

- recover the major independent channels;
- state how each secondary channel changes primary readings;
- preserve conditional channels;
- avoid turning branch resonance into replacement translation;
- preserve source and activation confidence separately.

### S100 stress test

Pass criteria:

- the opening unit is not treated as irrelevant;
- its operation is abstracted before analogy;
- at least three supported cross-block bridges are identified;
- active opening agency, passive exposure, and final knowledge remain distinct;
- later grave/chest exposure changes the perceived function of the opening before the final summary;
- secondary branches are not admitted merely because they are vivid.

### S103 stress test

Pass criteria:

- the opening oath remains active across the passage;
- multiple supported branches of the oath root remain visible when they perform different work;
- pressure, duration, restraint, or other channels are not collapsed without evidence;
- the exception sequence is modeled as a role-complete counter-system only where supported;
- spear or other remote images remain bounded secondary simulations.

## 3. Negative controls

Run at least one:

- shuffled order;
- root-matched passage with different construction;
- branch-frequency control;
- generic theme-density control.

A strong finding should lose force when its local trigger or order is removed.

## 4. Agent-count acceptance

The run fails when:

- more than three logical agents are used;
- different semantic shards are independently interpreted;
- Agent B writes the gold;
- Agent C discovers new findings;
- Agent A does not adjudicate every required audit action.

## 5. Recall threshold

For the gold-reference passage:

- all core channels recovered;
- at least 80% of medium-confidence gold channels recovered or explicitly represented as a close equivalent;
- no core channel suppressed by one dominant image;
- no supported conditional channel silently removed.

## 6. Precision threshold

Reject when:

- more than 10% of accepted findings lack a specific primary effect;
- any accepted finding is supported only by network membership or broad theme;
- any root-field resonance is written as an established local gloss without evidence;
- any progressive trajectory leaks later evidence.

## 7. Synthesis threshold

A reader must be able to answer for every major finding:

1. what the passage directly says;
2. which secondary branch is active;
3. what triggers it here;
4. what relation it creates;
5. what becomes newly visible in the primary reading;
6. what the word still does not mean.

## 8. Publication non-regression

The optional essay may be shorter than the notebook, but:

- it must not alter the gold;
- every required-body finding must be realized;
- conditional rhetoric must remain conditional;
- compact mode must not be used to flatten a full-macroblock passage;
- full mode must not manufacture complexity in a compact passage.

## 9. Release rule

Release the workflow only after:

- two independent runs on the gold-reference passage;
- two S100 runs;
- two S103 runs;
- at least one compact-passage control;
- clean schema and file-access audits;
- no agent-count violation.
