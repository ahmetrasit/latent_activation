# V9.0 — Theme Revelation from an Existing Reservoir

V9.0 changes only synthesis. It does not add a harvest stage, enlarge the
lexical field, or ask an author to rediscover material that earlier formation
passes already supplied.

The S1 hybrid proof showed that a reservoir can contain the important latent
formations while still failing to reveal them. Complete image chains were
distributed across participant architecture, formal observations, operational
formations, confidence qualifications, and a root ledger. The reader therefore
had to reconstruct the memorable theme that the synthesis was supposed to
make visible.

The second failure was premature polarity. A materially vivid operation could
be treated as threatening merely because its ordinary image sounded negative.
The author then used it only as a boundary or warning and failed to ask what
the passage's actual modifiers, participants, direction, and outcome made that
operation do.

V9.0 gives one persistent synthesis author two turns:

1. recompose the frozen reservoir as a compact map of coherent latent themes;
2. render that map as target-language prose.

The first turn separates material operation from moral polarity, tests the
operation inside the exact passage relation, and gathers dispersed components
into a complete image chain. Each retained finding must produce this movement:

```text
lexical surprise -> complete image chain -> changed hearing of the passage
```

Grammar, morphology, participant structure, and the primary contextual
reading remain governing constraints, but they should normally regulate the
synthesis invisibly rather than become its publication architecture.

There is no finding quota or word target. Compactness means eliminating
duplicated analysis, confidence machinery, inventories, and defensive
restatement; it never means cutting the links that make an image chain
intelligible.

## Controlled S1 test

The initial test uses the already completed S1 hybrid reservoir. The author is
not shown the gold/reference synthesis, comparisons, reviews, or named target
findings. Assessment compares only themes present in both the generated work
and the reference. Missing reference-only material is outside this test.
