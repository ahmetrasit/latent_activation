# v12 Cross-Run Publication v3

v3 publishes one immutable ordinary target-language baseline beside one flat
array of v12 contextual deltas for every ayah. It coexists with the v2
calibration workflow and does not rewrite its artifacts.

## Ayah model

```json
{
  "ayah_ref": "1:6",
  "baseline": {
    "source_ref": "1:6",
    "text": "fixed ordinary target-language translation",
    "target_tokens": [["Bizi", ["1:6:1"]]]
  },
  "findings": [
    {
      "text": "only what contextual activation adds or changes",
      "grade": "strong",
      "anchors": [["1:6:1", "root_000000", ["B003"]]]
    }
  ]
}
```

The baseline is a coordinator-owned, hash-bound input. The publication agent
sees it for the subtraction test but cannot emit or rewrite it. Finalization
injects it verbatim. Findings remain a single flat array; `strong`, `weak`, and
`reject` are finding-level grades.

## Language model

The workflow is not Turkish-specific. It binds:

- `baseline/methodology/ordinary_baseline_v1.md`;
- one BCP-47 language profile;
- one validated target-language baseline artifact;
- the language-neutral v3 publication contracts.

Turkish (`tr`) is the first profile. Adding another language requires a new
profile and baseline artifact, not new workflow code.

## Baseline validation

```bash
python3 _status/v12_cross_run/scripts/validate_target_language_baseline.py \
  BASELINE.json --surah SURAH --qac QAC.sqlite
```

The validator checks compact token shape, token identity against the baseline
text, QAC referential integrity, and complete QAC word coverage. No target token
or QAC word may be orphaned. Synthetic ayah-zero Basmalahs explicitly alias
canonical `1:1` QAC references.

## Package and close

```bash
python3 _status/v12_cross_run/scripts/build_publication_package_v3.py SURAH \
  --baseline BASELINE.json

python3 _status/v12_cross_run/scripts/finalize_publication_v3.py \
  _status/v12_cross_run/s###
```

The package gives the publisher two complete analytical readers, the fixed
baseline roster, the language profile, and the compact anchor map. The prompt
requires every finding to pass this test:

> If the target-language reader can derive the sentence from the baseline
> alone, it is not a finding.

Baseline-only source prose is therefore omitted before grading. Genuine
contextual or retrospective additions remain atomic, are rendered in the
target language, and are retained even when graded `reject`.

## Pilot gate

Before corpus production:

1. validate and editorially review the isolated S1 Turkish baseline;
2. build the S1 v3 package;
3. run one whole-surah publisher and its second-pass audit;
4. finalize and inspect baseline immutability, Turkish output, delta-only
   semantics, finding atomicity, source-surprise coverage, and anchors;
5. repeat on S2 as the largest practical context case.

Neither generated baseline wording nor v3 findings become canonical merely by
passing structural validation. Editorial pilot approval precedes freeze.
